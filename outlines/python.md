# Python

Duration: 4 months / 16 teaching weeks.
Schedule: 6 instructor-led hours weekly (96 total), plus 4 to 6 independent study hours.

Learn Python through eight chapters covering fundamentals, strings, numbers, logic, conditions, loops, data structures, and functions. The 16-week plan emphasizes independent programming, validation, and readable code.

## Prerequisites

Basic computer literacy; comfort with files and folders.

## Tools

Python 3.10 or later for match case; VS Code or another editor; standard library; optional Jupyter notebooks; Git.

## Learning outcomes

- Explain Python execution and write programs using variables, input, and core data types.
- Manipulate strings and numbers and implement decisions and loops.
- Select and use lists, tuples, sets, and dictionaries appropriately.
- Write clear functions with parameters and return values and validate program behavior.

## Weekly schedule

### Week 1 — Python Fundamentals

What Python is, execution, installation, comments and print().

Practical: Install Python and run a documented introductory script.

### Week 2 — Variables and data types

Variables, user input(), core types, conversions and validation.

Practical: Build a user-input calculator with type and value checks.

### Week 3 — String basics

String creation, transformations, indexing and slicing.

Practical: Extract and standardize fields from text records.

### Week 4 — String validation

Search, validation methods, case conversion and edge cases.

Practical: Create a reusable set of text-cleaning operations.

### Week 5 — Python Numbers

Integers, floats, math, rounding, random numbers and validation.

Practical: Build a numeric simulation and explain rounding choices.

### Week 6 — Logic and operators

Booleans, comparison, logical, membership and identity operators.

Practical: Write and verify business-rule expressions; compare equality and identity.

### Week 7 — Conditional statements

If, else, elif, nesting, advanced conditions, inline if and match case.

Practical: Build a rule-based classification program covering all decision branches.

### Week 8 — Midpoint practical

Fundamentals, strings, numbers, operators and conditions.

Practical: Complete an independent input-validation and classification task.

### Week 9 — Loop foundations

For loops, break, continue and pass.

Practical: Process a collection while handling skipped and invalid records.

### Week 10 — Advanced loops

For else, nested for loops and while loops.

Practical: Build a menu-driven program and explain loop termination.

### Week 11 — Lists and analysis

List overview, creation, access, unpacking and analysis.

Practical: Analyze a collection of transaction values.

### Week 12 — List operations

Adding, removing, updating, sorting and combining lists.

Practical: Maintain a transaction list with validated updates.

### Week 13 — Iterables and collections

Iterables, filtering, lambda, list comprehensions, tuples and sets.

Practical: Implement concise transformations and compare collection choices.

### Week 14 — Dictionaries and functions

Dictionaries; functions introduction; parameters and return values.

Practical: Create a dictionary-backed application using reusable functions.

### Week 15 — Clean functions and capstone

Function types, readable names, focused responsibilities and documentation.

Practical: Refactor the application into clean functions and test representative cases.

### Week 16 — Capstone presentation

End-to-end execution, functional validation, documentation and defense.

Practical: Demonstrate the final program and explain its design and limitations.

## Capstone

Transaction management and analysis program

Submit a menu-driven Python program using input validation, conditions, loops, lists or dictionaries, summary calculations, and reusable functions. Include source code, sample inputs and outputs, a functional test checklist, and a README.

## Assessment

- Weekly practical work: 25%
- Knowledge checks: 10%
- Midpoint practical: 20%
- Capstone artifact: 35%
- Presentation and defense: 10%

# AWS

Duration: 4 months / 16 teaching weeks.
Schedule: 6 instructor-led hours weekly (96 total), plus 4 to 6 independent study hours.

Build a practical foundation in AWS cloud architecture with an emphasis on secure, observable, cost-aware data workloads. This broad course supports later specialization in architecture or data engineering.

## Prerequisites

Basic networking and computer literacy; SQL and Python useful for data labs.

## Tools

AWS console and CLI; IAM; S3; EC2; VPC; RDS; Lambda; CloudWatch; Glue; Athena; approved lab accounts.

## Learning outcomes

- Explain cloud service models, AWS architecture concepts, and shared responsibility.
- Configure scoped identity permissions, storage, networking, and compute.
- Build a small analytics workflow using S3, Glue, and Athena.
- Document reliability, monitoring, recovery, and cost decisions.

## Weekly schedule

### Week 1 — Cloud foundations

Regions, Availability Zones, elasticity, service models, responsibility.

Practical: Map a business workload to cloud capabilities.

### Week 2 — Identity and billing

IAM roles and policies, MFA, temporary access, budgets and tagging.

Practical: Configure scoped lab access and spending notifications.

### Week 3 — Object storage

S3 objects, bucket access, encryption, lifecycle and versioning.

Practical: Create a secure data bucket and test access controls.

### Week 4 — Networking

VPCs, subnets, route tables, security groups, public versus private access.

Practical: Draw and implement a minimal network design.

### Week 5 — Compute

EC2, instance choices, EBS, scaling and operating responsibilities.

Practical: Deploy and monitor a small approved compute workload.

### Week 6 — Databases

RDS fundamentals, relational versus key-value patterns, backups.

Practical: Connect an application or script to a managed database.

### Week 7 — Serverless

Lambda, event triggers, permissions, limits and failure paths.

Practical: Validate an S3 event-driven processing function.

### Week 8 — Midpoint practical

Storage, access, compute and architecture decisions.

Practical: Demonstrate a secure foundational cloud environment.

### Week 9 — Monitoring

CloudWatch logs and metrics, alarms, CloudTrail audit concepts.

Practical: Detect and investigate a simulated application failure.

### Week 10 — Data catalog and queries

Glue Data Catalog, crawlers, Athena, partitions and query costs.

Practical: Catalog Parquet data and run validated analytical queries.

### Week 11 — Data processing

Glue jobs, transformations, schema handling and job monitoring.

Practical: Build a small source-to-curated processing job.

### Week 12 — Reliable architecture

Failure modes, backup, recovery, availability and scaling tradeoffs.

Practical: Test recovery and document restoration steps.

### Week 13 — Security and governance

KMS concepts, secrets, least privilege, audit and data classification.

Practical: Review the architecture against an access-control checklist.

### Week 14 — Automation and costs

Infrastructure as code concepts, CLI scripts, right-sizing and cleanup.

Practical: Create a repeatable deployment and estimate usage costs.

### Week 15 — Capstone build

Integration, validation, monitoring, budgets and documentation.

Practical: Run ingestion, transformation and analytics end to end.

### Week 16 — Capstone presentation

Architecture defense, live query demonstration and handover.

Practical: Explain security, reliability and cost tradeoffs with evidence.

## Capstone

Secure cloud analytics environment

Submit an architecture diagram, IAM design, reproducible deployment instructions, ingestion and query workflow, monitoring evidence, a cost estimate, and cleanup instructions.

## Assessment

- Weekly practical work: 25%
- Knowledge checks: 10%
- Midpoint practical: 20%
- Capstone artifact: 35%
- Presentation and defense: 10%
